# 抓取朝向解除镜头偏好

`behavior-grasp@0.1.24` 保留向下延伸和开合轴垂直视觉主轴的约束，在完整路径可达的前提下优先减小向下倾角，再减小关节运动。删除自动姿态初始化、操作躯干求解和路径评分中的镜头朝内偏好，以及参考四元数距离惩罚。两组绕夹爪延伸轴相差 180° 的朝向分别生成 IK 起点，参与原有多起点路径搜索。显式四元数继续使用指定朝向。

SDK、Ability、Runtime 接口及按钮流程沿用现有版本。相机朝向自由会改变物体相对于持物手的姿态；实际抓取和后续按钮识别仍需现场验证。

## 验证

- 朝向、主轴、左右臂完整路径、操作躯干、自动选手：81 项回归通过。
- 主轴及新增半周参考朝向不偏置解的检查：19 项通过，其中主轴用例与上一组有重叠。
- 历史现场记录离线全流程：左右臂都可达，最终倾角均约 0.5°；左臂最小关节余量 17.70°，右臂 5.00°，自动选择左臂。耗时 33.58 秒。
- 原始输入复用 validation/grasp-auto-side/snapshot.json，结果保存在外部集成目录 validation/grasp-camera-free/offline.json。

验证为离线运动学和 Skill 行为回归；未执行物理动作。路径检查沿用关节及采样约束，实际 Runtime 插值与碰撞仍需现场确认。
