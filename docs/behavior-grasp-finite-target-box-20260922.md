# 收臂及躯干过渡：有限目标包围盒检查

本地修改 `behavior_grasp/scripts/retract.py`，将目标前方的无限高平面约束替换为有限包围盒检查。读取已有 `source.object_bounds` 和底盘位姿，将连杆中心线转换到包围盒原始参考系，保留目标实际高度、宽度和深度。无需新的 Ability / SDK / Runtime 接口。

用线段与包围盒的分离轴检查相邻关节中心及工具中心间的整段连线，覆盖双臂收回、收回后的躯干过渡及实测收臂复核。保持已有的关节限位余量、双臂各自在躯干一侧及紧凑姿态约束。正的分离裕量表示不相交，该值为分离轴上的间隔，未使用虚构的连杆厚度或场景专用安全半径。
