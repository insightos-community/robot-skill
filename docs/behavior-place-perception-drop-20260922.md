# behavior-place 0.1.2：识别辅助顶部投放

持物尺寸与末端到物体的变换可一起省略，使用 prompt 调用现有 perception.locate_object，并结合 motion.get_end_effector_state 计算。显式输入两项几何仍可使用。

顶部 drop 可省略内部尺寸；进一步省略 target.region 时，通过 target.prompt 识别容器可见包围盒，结合 robot.get_state 的底盘姿态确定竖直方向，以包围盒顶部中心和水平投影尺寸近似开口。该模式明确采用开口朝上的假设，不判断真实内缘或内部障碍。

夹爪延伸方向在水平与竖直向下中选择转动较小的姿态，保留物体相对末端的变换，根据旋转后的物体投影厚度和 clearance_m 计算释放高度。该选择为几何计算，实际末端运动失败时停止张爪。释放成功后撤手；结果只确认释放和撤手动作。

普通 place 继续需要区域内部尺寸。所有逻辑使用现有 Ability，不增加 SDK、Runtime 或 Ability 接口。识别失败、置信度不足或坐标/尺寸无效会在移动之前停止。所有推断几何及来源记录到检查点和结果。

验证：49 项几何与流程测试通过；独立 Worker 输入校验通过。尚未执行此版本的真实物理投放。
