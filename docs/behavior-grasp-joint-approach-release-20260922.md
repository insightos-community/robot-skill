# behavior-grasp 0.1.26：联合收臂与直接接近

抓取规划现要求收臂姿态、躯干过渡和后续接近同时可行。两个手侧分别计算完整组合，显式手侧也使用同一规划入口。四个躯干关节均参与求解，物理动作依次执行收臂、躯干调整、预抓取、下降、闭爪和抬升。
