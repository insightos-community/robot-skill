# 操作腕依据持物末端观察

behavior-radio-button 0.1.28 流程：自然屈肘收臂 → 根据持物末端和操作腕标定规划观察位置 → 单目标移动 → 腕部按钮识别 → 按钮接近。
首次按钮未找到时保留既有轴向 180° 翻转，再规划观察位置并识别一次。

删除躯干直立及整物体识别。输入移除 object_ref/object_prompt，保留 operating_side、wrist_sensor_id 和原有按钮参数。
保持当前躯干，所有求解位于 Skill，复用已有 Action。SDK、Ability、Runtime 无改动。
观察光轴对准持物末端，左右操作侧镜像，距离使用实测相机到持物末端距离作为软偏好。
没有物体尺寸，求解只验证持物末端入镜；物体完整入镜、按钮可见性和碰撞仍需现场验证。

验证：执行顺序、失败停止、恢复、左右臂自然目标/观察目标/翻转及包结构共 26 项通过。
加入非直立姿态后两项左右镜像几何验证通过。该姿态取自本轮左手抓取后的躯干角，右手验证对腰部转向作镜像。
另行尝试右手沿用同一左侧腰部转向未找到自然屈肘解，未放宽约束或自动移动躯干。
独立打包 Worker initialize 和左右手 validate_input 通过。
本次更新不下发物理动作，现场结果由后续运行验证。
