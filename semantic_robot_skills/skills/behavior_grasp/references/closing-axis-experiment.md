# 开合轴约束试验

本分支抓取运动候选仅限制夹爪开合轴垂直于视觉主轴。固定本次识别计算得到的抓取位置，在两个剩余角度自由度各采样 8 个角度；按相对当前末端的转角排序。有限采样未找到路径不能证明连续姿态空间无解。

移除 Skill 包围几何筛选、水平或朝下偏好、相机朝向要求及预抓取距离/直线接近约束。输入已删除 pregrasp_offset_m；当前试验中 approach_preference 和显式 orientation_xyzw 不参与运动候选选择。候选均由 SDK/cuRobo 检查模型限位和碰撞。观察阶段与闭爪接触确认维持现有流程。

当前现场验证通过 Runtime 原子接口逐个请求 plan_only=true，抓取臂和四个躯干关节参与求解；底盘和另一手臂保持锁定。测试复用最近一次已识别物体位置和主轴，没有重复执行观察躯干动作，也未执行接近、闭爪或抬升。

该修改尚未发布到主部署的 Registry。
